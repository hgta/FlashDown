# Proposal: add-flashdown-mvp

## Why

FlashGet（网际快车，1999 年侯延堂开发，原名 JetCar）是中国第一款支持**多线程分块**与**断点续传**的下载软件，
其交互范式——左侧类别树、右侧任务网格、底部「块图 + Jet + 日志」面板、始终置顶的悬浮窗——
定义了一代人对"下载"这件事的视觉记忆。

二十年后的今天，桌面下载器要么演化为带云盘与广告的巨型客户端（迅雷），要么退化为命令行工具（aria2）。
**"看得见分块在跑"的那种确定感与满足感消失了。**

FlashDown 的目标：用现代技术栈（Go + Wails v3）复刻 FlashGet 的**经典形态与核心能力**，
交付一个干净、快速、无广告无捆绑、开箱即用的桌面下载管理器。

仓库当前为空（仅 MIT LICENSE），本项目为从零构建。

## What Changes

- **新建** 桌面应用代码库：Go 下载引擎 + Wails v3 外壳 + Vue 3 前端
- **新增** 多线程分块下载内核：文件切成自适应大小的块，N 个 Jet 并发领取，块级断点续传
- **新增** 任务管理：新建/暂停/继续/删除/重试、队列与并发上限、完成后重命名并归入类别目录
- **新增** 三档速度限制：全局、单任务、按时间段；滑动窗口测速与剩余时间估算
- **新增** 类别树与下载规则：默认「软件 / 游戏 / 驱动程序 / MP3」四类，按扩展名自动归类
- **新增** 批量下载：FlashGet 风格 `(*)` 通配符语法，支持数字/字母区间与步长
- **新增** 经典主窗口布局：菜单栏 + 工具栏 + 类别树 + 任务网格（单元格内进度条）+ 底部三页签面板 + 状态栏
- **新增** 悬浮窗：无边框、置顶、可拖动、可接收拖拽链接，实时速度曲线
- **新增** 系统托盘与剪贴板监视：关闭窗口隐藏到托盘，复制链接即提示新建任务
- **新增** 下载历史：查找、日志面板、导入/导出未完成列表

MVP 明确**不做**：FTP / BT / 磁链 / MMS-RTSP、浏览器扩展（Native Messaging）、镜像站点择优、
计划任务与完成后关机、MD5 校验、无头 RPC 模式。

## Capabilities

### New Capabilities

- `download-engine`: 分块下载内核 —— 块划分与工作队列、Jet 并发连接、随机写盘、断点续传、Range 降级、重试与错误分类
- `speed-limiting`: 全局 / 单任务 / 时间段三档限速，滑动窗口测速，剩余时间与速度曲线数据
- `task-management`: 任务 CRUD、状态机、队列与并发上限、新建任务对话框、完成后重命名与归档
- `category-rules`: 类别树（软件/游戏/驱动程序/MP3）、类别独立目录、按扩展名的下载规则
- `batch-download`: 通配符批量任务 `( * )`、数字/字母区间、步长、多括号笛卡尔积
- `main-window-ui`: 主窗口经典布局与现代渲染（任务网格、块图/Jet/日志三页签、状态栏、明暗主题）
- `floating-window`: 悬浮窗（无边框置顶可拖动）+ 拖放篮 + 速度曲线
- `system-tray`: 系统托盘图标、右键菜单、关闭窗口隐藏到托盘
- `clipboard-monitor`: 剪贴板监视，识别链接并提示新建任务
- `download-history`: 下载历史、查找、日志面板、导入/导出未完成列表

### Modified Capabilities

（无 —— 全新项目，无既有规格）

## Impact

- **代码库**：`FlashDown/` 新建单模块 Go 工程；`internal/engine` 不依赖 UI，可独立单测与无头运行
- **运行时依赖**：Go 1.25+（当前为 1.22.12，**必须升级**）、Node 25（已有）、Windows WebView2 Runtime（Win10/11 自带）
- **第三方**：`github.com/wailsapp/wails/v3`（Beta，需在 `go.mod` 锁死版本）
- **磁盘产物**：下载目录内 `<name>.fd!`（数据）与 `<name>.fd!.state`（状态日志），完成后重命名为正式文件名
- **配置与历史**：`%APPDATA%\FlashDown\config.json`、`%APPDATA%\FlashDown\history.jsonl`
- **平台范围**：首选 Windows（当前开发环境）；Go 与 Wails 本身跨平台，但 Linux/macOS 构建需额外系统依赖，MVP 不验证
